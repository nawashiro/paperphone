# Spec Delta

## Purpose

外出時に持ち歩く紙の地図として、利用者が指定した出発地と目的地の場所検索、徒歩経路、印刷地図を提供する。都道府県単位でローカルに取得したOSMデータを使用し、外部地図サービス・APIキー・課金に依存せず、ODbLの帰属表示を守る。

## ADDED Requirements

### Requirement: 都道府県OSMデータの取得と保持
アプリはPCの現在地または利用者の選択から都道府県を判定し、対応するOSM抽出（.osm.pbf）を日次で更新される抽出元から取得・更新できなければならない（SHALL）。保存済み抽出は利用者がボタンを押さずに自動で読み込み、読込の進捗はプログレスバーで示し、更新だけは利用者の明示した時点で行わなければならない（SHALL）。保存済みデータと更新のボタンは同一画面に置き、「オフライン」や「座標を送りません」といった説明文を別途出してはならない（MUST NOT）。保存済みデータの削除手段を設定から提供しなければならない（SHALL）。取得に失敗した場合は失敗を短く示し、地図ページを除いた冊子作成を継続できなければならない（SHALL）。

#### Scenario: 現在地から都道府県を判定する
- **WHEN** 位置情報が許可され、現在地が内蔵の都道府県境界辞書で判定できる
- **THEN** 対応する都道府県が既定で選ばれ、保存済みの抽出が自動で読み込まれる

#### Scenario: データの削除
- **WHEN** 利用者が設定から地図データの削除を選ぶ
- **THEN** アプリ専用カタログ内の抽出ファイルとmanifestが削除され、内蔵辞書や他の設定に影響しない

#### Scenario: 取得失敗時に冊子を続ける
- **WHEN** 通信失敗や抽出の不在でOSMデータを取得できない
- **THEN** 失敗理由を表示し、地図ページを除いた冊子を他の内容で生成できる

#### Scenario: 取得済みデータを再利用する
- **WHEN** 同じ都道府県の抽出が既に存在する
- **THEN** 条件付き確認後に不要な再ダウンロードをせず、基準日と更新可否を表示する

### Requirement: 場所検索はローカルで完結する
アプリは取得した都道府県のOSMデータから構築したローカルインデックスで出発地と目的地を検索しなければならない（SHALL）。検索中に外部の位置情報サービス・Web APIを呼び出してはならない（MUST NOT）。検索は利用者の入力と同時に候補を出し、検索・取り消しのための専用ボタンを置いてはならない（MUST NOT）。候補と選択結果の表示は人間可読な名称だけにし、種別名・座標・内部IDや現在地の機械向けラベルを載せない。内部データには引き続き種別と座標を持つ。

#### Scenario: 入力と並行した候補
- **WHEN** 利用者が検索窓に文字を入れる
- **THEN** 選択ボタンを押さずに、ローカルの候補が名称だけの状態で並び、選択できる。候負を小さい窓に納めず、すべて普通のウィンドウへ並べ、選択後に候負を消す

#### Scenario: 曖昧な名前で探す
- **WHEN** 部分一致や異なる表記（漢字・かな・英語名など）で入力する
- **THEN** 名称だけの候補一覧が提示され、利用者は名称から応じた地点を選択できる

#### Scenario: 検索結果がない
- **WHEN** インデックスに一致する地点がない
- **THEN** 結果なしを短く示し、架空の地点を出さず、他の機能の利用は妨げない

#### Scenario: 現在地を出発地にする
- **WHEN** 位置情報が許可され、現在地が抽出範囲内にある
- **THEN** 現在地を既定の出発地候補として選択できる

### Requirement: 徒歩経路の取得
アプリはローカルに構築された歩行者グラフで出発地と目的地の間の徒歩経路を取得し、経路・距離・目安時間を紙面モデルへ提供しなければならない（SHALL）。歩行者グラフと地図表示データをメモリ内でキャッシュし、同じ抽出版・同じ探索範囲の再生成でPBF/XMLの再走査を省かなければならない（SHALL）。キャッシュをディスクへ書き出してはならない（MUST NOT）。実在しない経路を推測して描いてはならない（MUST NOT）。

#### Scenario: 徒歩経路が存在しない
- **WHEN** グラフ上に到達可能な経路が返らない
- **THEN** 経路なしと表示し、地図機能を除いて出力を続けられる

#### Scenario: 抽出範囲外の地点
- **WHEN** 出発地または目的地が都道府県抽出の範囲外にある
- **THEN** 実現できない理由を明示し、架空の経路を描かない

#### Scenario: 通信なしで経路を得る
- **WHEN** 取得済みのOSMデータとインデックスが存在する
- **THEN** ネットワーク接続なしで検索・経路・地図描画を完了できる

### Requirement: 印刷地図と帰属
アプリはローカルのOSMデータから地図ページをCairoで描画し、生成PDFにベクタとして組込まなければならない（SHALL）。地図ページには「© OpenStreetMap contributors」とODbL参照を1行で判読可能な形で載せなければならない（SHALL）。出発地・目的地の名称、抽出のデータ基準日、道路までのずれ、距離・時間の注記を地図ページに載せてはならない（MUST NOT）。地図の範囲と縮尺は出発地・目的地・経路が収まるように選ばれなければならない（SHALL）。地図の配色は白黒印刷で読める晴度を使わなければならない（SHALL）。

#### Scenario: 地図ページの注記
- **WHEN** 利用者が冊子に徒歩地図を入れて生成する
- **THEN** 地図ページの注記は「© OpenStreetMap contributors · ODbL 1.0」とスタイル由来の権利表示だけになり、出発地・目的地の地名や基準日は載らない

#### Scenario: 地図をPDFに掲載する
- **WHEN** 地図ページを冊子に含める
- **THEN** 出典・帰属・データ基準日が判読可能で、印刷時にも判読できる

#### Scenario: 経路入り地図の整合
- **WHEN** 取得済みの経路を地図ページに重ねる
- **THEN** 経路と両地点が地図の範囲内に収まり、縮尺が内容と一致する
