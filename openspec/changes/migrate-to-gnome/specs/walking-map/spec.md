# Spec Delta

## Purpose

外出時に持ち歩く地図として、利用者が指定した出発地と目的地の場所検索、徒歩経路と地図を提供する。Google Mapsの利用条件を維持しながら、利用者自身がAPIキーと課金を管理できるようにする。

## ADDED Requirements

### Requirement: 利用者自身のAPIキー
アプリは利用者自身のGoogle Maps APIキーを設定・置換・削除できるようにし、必要なAPIと課金の設定を案内しなければならない（SHALL）。配布物に共通秘密キーを埋め込まず、キーをログや生成PDFへ露出してはならない（MUST NOT）。

#### Scenario: キーが設定されていない
- **WHEN** APIキーなしで地図機能を開く
- **THEN** 設定方法を案内し、地図以外の機能は利用可能にする

#### Scenario: APIキーを削除する
- **WHEN** 利用者が設定からキーを削除する
- **THEN** 保存済みキーを削除し、そのキーで新しいリクエストを送信しない

### Requirement: 場所検索と徒歩経路
アプリはGoogle Mapsのサービスで出発地と目的地を検索・確認し、徒歩モードで経路を取得しなければならない（SHALL）。経路と地点はGoogle Mapsの地図上に表示しなければならない（SHALL）。

#### Scenario: 出発地と目的地を指定する
- **WHEN** 利用者が検索結果から出発地と目的地を選ぶ
- **THEN** 両地点を確認でき、徒歩経路を重ねたGoogle Maps地図を冊子用に取得できる

### Requirement: 印刷地図の帰属と失敗の扱い
アプリはGoogle Mapsの地図と帰属表示を判読可能な形でプレビュー・印刷しなければならない（SHALL）。認証失敗、割当超過、通信失敗、徒歩経路なしを区別して表示し、地図なしの冊子作成を妨げてはならない（MUST NOT）。

#### Scenario: 徒歩経路が存在しない
- **WHEN** 指定した地点間に徒歩経路が返らない
- **THEN** 経路なしと表示し、架空の経路を描かず、地図機能を除いて出力を続けられる

#### Scenario: 地図をPDFに掲載する
- **WHEN** 取得したGoogle Maps地図をPDFに含める
- **THEN** 帰属表示を切り落としたり隠したりせず、印刷時にも判読できる
