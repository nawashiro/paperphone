# Spec Delta

## Purpose

PCの現在地に対応する今日の短期予報を冊子に掲載し、外出時に必要な気温と天気を確認できるようにする。目安の時刻と実際の予報対象時刻を混同せず、取得できない時間帯や出典を明示する。

## ADDED Requirements

### Requirement: 現在地の短期予報
アプリは許可されたPCの現在地を用いてMET Norway Locationforecast JSONを直接取得し、今日の短期予報の気温と天気を提供しなければならない（SHALL）。長期予報や過去の天気を短期予報の代わりとして使用してはならない（MUST NOT）。

#### Scenario: 今日の予報を取得する
- **WHEN** 現在地と予報サービスが利用可能である
- **THEN** システムの今日に対応する短期予報を利用し、地点と取得状況を確認できる

### Requirement: 目安時刻に近い異なる予報を選ぶ
アプリは今日の9時・12時・18時を目安に、同日の短期予報から各目安の前後90分以内で最も近い予報を選ばなければならない（SHALL）。同距離なら後の時刻を優先し、同一予報を複数枠に重複使用してはならない（MUST NOT）。候補がない枠は空欄のまま残す（MUST）。

#### Scenario: 完全一致する予報
- **WHEN** 今日の9時・12時・18時の短期予報が利用可能である
- **THEN** それぞれの時刻の予報を対応する枠に選ぶ

#### Scenario: 過ぎた時間帯は出さない
- **WHEN** 18時枠の選択窓が閉じた後に天気を開く
- **THEN** 今日の予報の取得をせず、「今日の天気はもうありません。」を短い文言として表示し、翌日の予報で補わない

#### Scenario: 短期の期間情報がない
- **WHEN** 気温と6時間の天気記号はあるが `next_1_hours` がない
- **THEN** その項目を短期予報候補にせず、6時間の天気を1時間の天気と偽らない

### Requirement: 予報の実時刻を表示する
アプリは予報の実際の対象時刻をシステムのタイムゾーンでUIと冊子に表示し、天気記号の対象期間を確認可能にしなければならない（SHALL）。気温の瞬間値と期間の天気を区別しなければならない（SHALL）。表示は当日の紙面に合う短い時刻表記（時刻のみ）でなければならず（SHALL）、日付・UTCオフセット・キャッシュ日時・天気コードなどの機械向け列を冊子とUIに載せてはならない（MUST NOT）。短期の天気記号はJSONの `next_1_hours` に基づく開始・終了を保持し、これがない項目を中期の天気記号で補ってはならない（MUST NOT）。

#### Scenario: 9時30分の予報を印刷する
- **WHEN** 9時の目安枠に9時30分の予報が選ばれる
- **THEN** 印刷する時刻は9時30分となり、UIでは天気記号が表す時間帯も確認できる

#### Scenario: 短期の期間情報がない
- **WHEN** 気温と6時間の天気記号はあるが `next_1_hours` がない
- **THEN** その項目を短期予報候補にせず、6時間の天気を1時間の天気と偽らない

### Requirement: 出典とサービス利用条件
アプリはMET Norwayの出典とライセンスをアプリ内および印刷物で1行の短い帰属表示で案内しなければならない（SHALL）。表示は「MET Norway · CC-BY 4.0」のような短い形とし、参照先URLを併記してはならない（MUST NOT）。抜粋・整形であることは冊子内の別の場所（READMEやdocsなどの説明）に記す。取得はアプリ識別子・バージョン・連絡先を含むUser-Agentを伴い、HTTPキャッシュと再取得間隔のサービス条件を満たさなければならない（SHALL）。座標と予報応答のキャッシュはメモリ内に限定し、座標入りURL・応答・識別用連絡先をログやディスクキャッシュへ保存してはならない（MUST NOT）。

#### Scenario: 冊子に予報を掲載する
- **WHEN** MET Norwayの予報を冊子に掲載する
- **THEN** 「MET Norway · CC-BY 4.0」の1行だけが末尾に載り、参照先URLや説明は紙面に出ない

#### Scenario: 有効なキャッシュがある
- **WHEN** 同一地点の予報がサービス条件に基づく有効期間内にある
- **THEN** メモリ内のキャッシュを再利用して不要な再取得を行わず、取得時刻を確認できる

#### Scenario: キャッシュの期限が切れる
- **WHEN** 保存されたHTTP有効期限を過ぎ、検証用ヘッダーが利用可能である
- **THEN** 条件付き取得を行い、304の場合は予報内容を維持して有効期限を更新する

#### Scenario: アプリを終了する
- **WHEN** 座標と予報応答がメモリ内キャッシュにある状態で終了する
- **THEN** アプリはキャッシュをディスクへ書き出さない
