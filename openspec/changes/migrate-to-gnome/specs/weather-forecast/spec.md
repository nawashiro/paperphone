# Spec Delta

## Purpose

PCの現在地に対応する今日の短期予報を冊子に掲載し、外出時に必要な気温と天気を確認できるようにする。目安の時刻と実際の予報対象時刻を混同せず、取得できない時間帯や出典を明示する。

## ADDED Requirements

### Requirement: 現在地の短期予報
アプリは許可されたPCの現在地を用いてMET Norwayの今日の短期予報を取得し、気温と天気を提供しなければならない（SHALL）。長期予報や過去の天気を短期予報の代わりとして使用してはならない（MUST NOT）。

#### Scenario: 今日の予報を取得する
- **WHEN** 現在地と予報サービスが利用可能である
- **THEN** システムの今日に対応する短期予報を利用し、地点と取得状況を確認できる

### Requirement: 目安時刻に近い異なる予報を選ぶ
アプリは今日の9時・12時・18時を目安に、同日の短期予報から各目安の前後90分以内で最も近い予報を選ばなければならない（SHALL）。同距離なら後の時刻を優先し、同一予報を複数枠に重複使用してはならない（MUST NOT）。候補がない枠は取得不能と示さなければならない（SHALL）。

#### Scenario: 完全一致する予報
- **WHEN** 今日の9時・12時・18時の短期予報が利用可能である
- **THEN** それぞれの時刻の予報を対応する枠に選ぶ

#### Scenario: システムの時差が30分単位
- **WHEN** 目安の9時に対して8時30分と9時30分の予報が同じ距離にある
- **THEN** 9時30分を選び、9時の予報として偽って表示しない

#### Scenario: 過ぎた時間帯が提供されない
- **WHEN** 最新の一覧に9時前後90分以内の予報が残っていない
- **THEN** 朝の枠を取得不能と示し、昼や夕方の予報で埋めない

### Requirement: 予報の実時刻を表示する
アプリは予報の実際の対象時刻をシステムのタイムゾーンでUIと冊子に表示し、天気記号の対象期間を確認可能にしなければならない（SHALL）。気温の瞬間値と期間の天気を区別しなければならない（SHALL）。

#### Scenario: 9時30分の予報を印刷する
- **WHEN** 9時の目安枠に9時30分の予報が選ばれる
- **THEN** 印刷する時刻は9時30分となり、UIでは天気記号が表す時間帯も確認できる

### Requirement: 出典とサービス利用条件
アプリはMET Norwayの出典とライセンスをアプリ内および印刷物で案内し、抜粋・整形したことを明示しなければならない（SHALL）。取得は識別可能なクライアント情報を伴い、キャッシュと再取得間隔のサービス条件を満たさなければならない（SHALL）。

#### Scenario: 冊子に予報を掲載する
- **WHEN** MET Norwayの予報を冊子に掲載する
- **THEN** 小さな注記でMET Norway由来の抜粋・整形データであることとライセンス参照先を示す

#### Scenario: 有効なキャッシュがある
- **WHEN** 同一地点の予報がサービス条件に基づく有効期間内にある
- **THEN** キャッシュを再利用して不要な再取得を行わず、取得時刻を確認できる
