# Spec Delta

## Purpose

既存Paper Phoneの折り畳み冊子の使い勝手と紙面構成を維持し、デスクトップで選択した情報を持ち歩けるようにする。UIとは独立した紙面として、日本語を含む内容のプレビュー、PDF保存と印刷を提供する。

## ADDED Requirements

### Requirement: 既存の折り畳み配置
アプリは既存のA4横・8区画の配置、区画ごとの回転、余白と折り目の目印を維持しなければならない（SHALL）。地図選択時は既存相当の追加地図ページを生成しなければならない（SHALL）。GNOMEの画面装飾を紙面に持ち込んではならない（MUST NOT）。

#### Scenario: 全区画を含む冊子
- **WHEN** 全コンテンツを選択して生成する
- **THEN** 基準PDFと同じ区画配置と向きになり、折り畳んだ後に各内容を読める

#### Scenario: 地図を追加する
- **WHEN** 利用可能な地図を選択して生成する
- **THEN** 主ページの区画配置を変えず、追加ページに地図を含める

### Requirement: 既存の掲載内容を引き継ぐ
アプリは表紙の名前、連絡先、予定、TODO、天気、写真、ドット方眼メモ、既存の紙アプリ素材とカード用切り込みガイドの選択を提供しなければならない（SHALL）。写真ページと紙アプリページを分け、異なる内容を同じページに混在させない（MUST NOT）。写真が選ばれているときはプレビューを表示しなければならない（SHALL）。未選択区画は既存相当の空欄またはドット方眼とし、折り方の案内を利用可能にしなければならない（SHALL）。折り方の案内は折り方そのものを短く示し、両面の綴じ方向や「印刷結果をよく見てから折る」という追加の免責的な指示を載せてはならない（MUST NOT）。

#### Scenario: 写真と紙アプリを選択する
- **WHEN** 利用者がローカル写真と既存素材の紙アプリを選び、メモを有効にする
- **THEN** 写真はプレビューで確認でき、紙アプリは別ページで選択でき、折り方の案内は折り方そのものだけを示す

#### Scenario: カード用ガイドを有効にする
- **WHEN** 利用者がカード用切り込みガイドを選択する
- **THEN** 既存相当の位置に切り込みの目印を描画し、競合する紙アプリ部分は既存と同じ扱いにする

### Requirement: 日本語と内容の収容
アプリは日本語の氏名・予定・TODOを文字欠けなく表示・印刷し、既存相当の文字サイズと区画境界を維持しなければならない（SHALL）。収容できない内容を無通知で失ってはならない（MUST NOT）。

#### Scenario: 長い日本語の予定
- **WHEN** 区画に収まらない長さまたは件数の日本語の予定を選択する
- **THEN** 文字化けや隣区画へのはみ出しを防ぎ、省略・未掲載があることをプレビューで示す

### Requirement: 同一内容のプレビューとPDFと印刷
アプリは生成した同一の紙面をプレビュー、PDF保存と印刷に使用しなければならない（SHALL）。保存・印刷の取消や失敗で利用者の既存ファイルを削除してはならない（MUST NOT）。PDFの配色は白黒印刷で読める晴度に限り、カラー印刷のみで判読できる描画にしてはならない（MUST NOT）。

#### Scenario: プレビュー後の保存と印刷
- **WHEN** 利用者が冊子をプレビューしてPDF保存または印刷を行う
- **THEN** 確認した紙面と同じ内容・ページ数・配置を出力する

#### Scenario: 保存の取消
- **WHEN** 利用者が保存ダイアログを取り消す
- **THEN** 既存ファイルを変更せず、編集内容とプレビューを維持する
