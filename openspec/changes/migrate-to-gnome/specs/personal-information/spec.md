# Spec Delta

## Purpose

デスクトップに登録された予定・連絡先・CalDAV由来のTODOを読み取り、外出に必要な情報を利用者が冊子へ選べるようにする。TODOの着手・期限と予定の日時の意味を保持し、認知負荷の低い分類を提供する。

## ADDED Requirements

### Requirement: デスクトップの個人情報を読み取る
アプリはEDSに登録されたカレンダー、タスクリストとアドレス帳を列挙し、利用者が読取元を選べるようにしなければならない（SHALL）。利用者が許可した元データの読取は行ってよいが、EDS経由・CalDAV経由を問わず、元データへの作成・変更・削除・完了状態の書戻しを行ってはならない（MUST NOT）。

#### Scenario: Thunderbird由来のTODOを読み取る
- **WHEN** ThunderbirdでCalDAVへ保存した未完了のVTODOがEDSのタスクリストに同期されている
- **THEN** アプリは件名、着手日時、期限、完了状態を読み取り、印刷候補として提示する

#### Scenario: CalDAVの登録データを読み取り専用で扱う
- **WHEN** アプリがEDS経由でCalDAV登録済みのVTODOを取得する
- **THEN** 件名・着手・期限・完了状態を読み取るだけとし、サーバー上のタスクを作成・変更・削除しない

#### Scenario: CalDAV上のTODO変更を反映する
- **WHEN** 利用者がCalDAVタスクリストを更新し、EDSのCalendarViewがVTODO変更通知を送る
- **THEN** アプリは対象リストを再読込し、変更後の件名・着手・期限・完了状態を候補へ反映する

#### Scenario: 連絡先を選択する
- **WHEN** 利用者がアドレス帳を選ぶ
- **THEN** 氏名と電話番号を含む連絡先を印刷候補として表示し、元のアドレス帳を変更しない

### Requirement: 今日に重なる予定
アプリはシステムの今日に重なる予定を、繰り返しの例外と変更を反映して表示しなければならない（SHALL）。終日予定は日付として扱い、時差変換で別日に移してはならない（MUST NOT）。

#### Scenario: 日をまたぐ繰り返し予定
- **WHEN** 前日から今日に重なる繰り返し予定があり、今日の回に個別変更がある
- **THEN** 今日に重なる変更後の予定を重複なく表示する

#### Scenario: 終日予定
- **WHEN** 終日予定を異なるシステムタイムゾーンで表示する
- **THEN** 元の日付の終日予定として表示し、架空の開始・終了時刻を付けない

### Requirement: 未完了TODOの分類
アプリは未完了TODOだけを「今日」「今後」「期限なし」に一意に分類しなければならない（SHALL）。着手が未来なら「今後」、着手済みなら期限の有無によらず「今日」、着手なし・期限ありは「今日」、両方なしは「期限なし」としなければならない（SHALL）。統合した全件一覧や独立した期限切れカテゴリを設けてはならない（MUST NOT）。

#### Scenario: 期限なしで着手が未来
- **WHEN** 未完了TODOに未来の着手日時があり、期限がない
- **THEN** 「今後」だけに表示する

#### Scenario: 着手日時に到達する
- **WHEN** 未完了TODOの着手日時に現在時刻が到達する
- **THEN** 再判定後は「今日」だけに表示する

#### Scenario: 着手なしで将来の期限がある
- **WHEN** 未完了TODOに着手日時がなく、将来の期限がある
- **THEN** 「今日」に表示する

#### Scenario: 日時の指定がない
- **WHEN** 未完了TODOに着手日時も期限もない
- **THEN** 「期限なし」だけに表示する

#### Scenario: 完了済みタスク
- **WHEN** タスクが完了状態または完了日時を持つ
- **THEN** どのカテゴリにも表示せず、印刷候補に含めない

### Requirement: 期限切れの控えめな表示
アプリは期限を過ぎた未完了TODOに小さく識別可能な「期限切れ」表示を付けなければならない（SHALL）。日付だけの期限はシステムのその日の終了まで期限内とし、時刻付き期限は指定時刻を過ぎた時点で期限切れとしなければならない（SHALL）。

#### Scenario: 期限切れを今日に表示する
- **WHEN** 着手済みまたは着手日時なしのTODOが期限を過ぎる
- **THEN** 「今日」に含めたまま控えめな期限切れ表示を付ける

#### Scenario: 日付だけの期限
- **WHEN** 期限が今日の日付だけで指定されている
- **THEN** 今日の間は期限切れにせず、翌日の開始から期限切れ表示を付ける

### Requirement: 個別の印刷対象選択
アプリは予定・連絡先・TODOの印刷対象を利用者自身が選べるようにし、選択した項目だけを冊子に含めなければならない（SHALL）。TODOのカテゴリ切替で選択を失ってはならない（MUST NOT）。

#### Scenario: 複数カテゴリからTODOを選ぶ
- **WHEN** 利用者が「今日」と「今後」のTODOを選びプレビューする
- **THEN** 選んだTODOだけが含まれ、カテゴリ切替によって以前の選択が解除されない

#### Scenario: 選択後に完了したTODO
- **WHEN** 選択したTODOが更新取得で完了済みと分かる
- **THEN** 印刷対象から除外し、選択内容が変わったことを利用者に通知する
