# Spec Delta

## Purpose

このcapabilityは、PC 用アプリの画面文言・状態表示の正しさを扱う。本deltaは、翻訳機構と日時表示が利用者に自然な形で見えることを規格に加える。

## ADDED Requirements

### Requirement: 空文言と翻訳の整合

文言の翻訳は、空文字列をそのまま空として扱い、翻訳カタログの内部文字列（ヘッダー等）がをUIに出してはならない（MUST NOT）。日本語カタログが載せる文言は、対応するmsgidの意図と一致しなければならない（SHALL）。

#### Scenario: 天気が取れた直後の状態語

- **WHEN** 天気の取得が成功して状態がREADYになる
- **THEN** 状態語は空で表示は変わらず、カタログヘッダー（Project-Id-Version等）の文字列はどこの画面にも現れない

#### Scenario: 地図の抽出が使えないとき

- **WHEN** 地図の抽出が存在しないか変換に失敗する
- **THEN** 地図領域の状態語は地図の失敗の意味を示し、天気の成功を含む別機能の文言が現れない

### Requirement: UIの日時は人間向け表記

UI上に表示する日付・日時は、システムロケールに沿った読みやすい表記（日本語では「2026年11月10日 17:30」相当）でなければならない（SHALL）。`2026-11-10 17:30` のような機械向けのISO-8601表記をそのまま載せてはならない（MUST NOT）。内部データ・保存ファイル・試験fixture・医師の診断将来出力はこの表記の対象外である（SHALL）。

#### Scenario: タスク一覧の期限を見る

- **WHEN** Tasks一覧に期限つきのタスクが載る
- **THEN** 期限はロケールの日付・時刻の読みやすい表記で示され、「2026-11-20」のようなISO文字列は現れない

### Requirement: 同一画面での帰属の重複禁止

同一の帰属性表示（MET Norway など）は、同一の画面領域内で一度だけ示さなければならない（MUST）。画面と冊子で帰属を分けて持つことは、どちらかの領域の縛りとして複製を強制してはならない（MUST NOT）。

#### Scenario: 天気を取得した後の画面

- **WHEN** 天気の領域に取得済みの予報が表示される
- **THEN** MET Norwayの帰属はその領域に一度だけ現れる
