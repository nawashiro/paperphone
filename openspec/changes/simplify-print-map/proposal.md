# Proposal

## Why

派生データはPBFの頂点を全数保持しており、印刷地図の幾何に紙で判別できない点まで入る。県規模の抽出では地物照会の返す点数が変わらずに増え続け、これが描画とデータ保持の両方で派生データの次の不満になる。加えて地名ラベルは全件を等価に扱うため、重なりで省略するとき、重要な地名が先に消える。

前回の軽量化（`lighten-osm-pipeline`）は応答時間を「抽出版ごとに1回の構築」へ寄せた。この提案は構築済みの内容そのものを減らす、その次の一段である。

## What Changes

- 派生データの生成時に、同じ道路種別で連続するwayを1レコードへ統合する（CoMaps `metalines_builder.cpp` 相当）。
- 派生データの生成時に、印刷で判別できない程度の余計な点を道路と面の幾何から捨てる（CoMaps が構築時にスケール行ごとへ簡素化を前倒しする `generator_tool` 第3パス相当。紙面縮尺1種類のためεは1段階）。
- 地名ラベルに重要度を持たせ、印刷地図は重要度の高い地名から描画する。重なりで省略するときも重要な地名が残る。
- **BREAKING** 派生データの版を上げる。旧版の派生データは読み替えず破棄し、新版を再構築する（版付き派生データの既定の振る舞いに従う）。

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

- `walking-map`: `派生データの生成と保持` に、印刷地図用幾何（道路の種別統合・簡素化済み幾何、面の簡素化済みリング、ラベル重要度）を内容として加える。`印刷地図と帰属` に、ラベルは重要度の高いものから描き、重要な地名が省略で残ることと、幾何の簡素化を実行時に繰り返さないことを加える。検索・経路・取得と保持のrequirementsは触れない。

## Impact

- `src/paperphone/osm_derived.py`: スキーマの版上げ（`DERIVED_VERSION`）、`_scan_places_and_features` にway統合と簡素化を追加、`map_labels` 列と重要度決定。
- `src/paperphone/map_rendering.py`: ラベル照会に重要度順を加える。幾何描画・帰属・overflow振る舞いは変えない。
- 依存は増やさない。shapelyの幾何簡素化は構築側でのみ新たに使用する。
- 調査の根拠と決定は `design.md`、作業は `tasks.md` に置く。
