# Spec Delta

## MODIFIED Requirements

### Requirement: 印刷地図と帰属
アプリはローカルのOSMデータから地図ページをCairoで描画し、生成PDFにベクタとして組込まなければならない（SHALL）。地図ページには「© OpenStreetMap contributors」とODbL参照を1行で判読可能な形で載せなければならない（SHALL）。出発地・目的地の名称、抽出のデータ基準日、道路までのずれ、距離・時間の注記を地図ページに載せてはならない（MUST NOT）。地図の範囲と縮尺は出発地・目的地・経路が収まるように選ばれなければならない（SHALL）。地図の配色は白黒印刷で読める濃度を使わなければならない（SHALL）。表示範囲内の地名ラベルは重要度の高いものから描き、重なりで省略するときも重要度の高い地名が残らなければならない（SHALL）。道路と面の幾何は印刷で判別できる精度を保ったまま、構築時にすでに簡素化・統合済みでなければならず（SHALL）、描画のたびに幾何を簡素化してはならない（MUST NOT）。

#### Scenario: 地図ページの注記
- **WHEN** 利用者が冊子に徒歩地図を入れて生成する
- **THEN** 地図ページの注記は「© OpenStreetMap contributors · ODbL 1.0」とスタイル由来の権利表示だけになり、出発地・目的地の地名や基準日は載らない

#### Scenario: 地図をPDFに掲載する
- **WHEN** 地図ページを冊子に含める
- **THEN** 出典・帰属・データ基準日が判読可能で、印刷時にも判読できる

#### Scenario: 経路入り地図の整合
- **WHEN** 取得済みの経路を地図ページに重ねる
- **THEN** 経路と両地点が地図の範囲内に収まり、縮尺が内容と一致する

#### Scenario: 重なりで省かれるのがどこか
- **WHEN** 地名ラベルが互いに重なる余地がほとんどない狭い範囲にあり、全ては描き切れない
- **THEN** 重要度の低い背景地物のラベルから省かれ、町名・駅名のような重要度の高い地名は残る

#### Scenario: 繰り返し描画
- **WHEN** 同じ抽出版に対して地図ページを繰り返し生成する
- **THEN** 前回と同じ地物幾何が使われ、描画ごとの簡素化計算をしない

### Requirement: 派生データの生成と保持
アプリは都道府県抽出の保存・更新の直後に、その抽出版に対応する地名索引と歩行者グラフを含む派生データを一度だけ生成しなければならない（SHALL）。派生データの生成中は進捗を表示し、取り消せても取り消し後に索引やグラフの一部分だけを使ってはならない（MUST NOT）。派生データの先頭は抽出版に紐付き、版が変わった時だけ再生成しなければならない（MUST）。派生データの削除は抽出データの削除に含めなければならない（SHALL）。生成に失敗した場合はその理由を短く示し、地図機能を除いた冊子作成を継続できなければならない（SHALL）。派生データの印刷地図用幾何は、同じ道路種別で連続する区間を統合し、面のリングと共に印刷で判別できない余計な点を構築時に捨てた形で格納しなければならない（SHALL）。地名ラベルには重要度を含めなければならない（SHALL）。

#### Scenario: 取得直後の生成
- **WHEN** 新しい抽出版が保存される
- **THEN** 派生データの生成が始まり、進捗が表示され、完了後に検索・経路が派生データを利用する

#### Scenario: 版が替わった時の再構築
- **WHEN** 利用者が抽出を更新して版が変わる
- **THEN** 旧版の派生データは廃棄され、新版に対応する派生データが再び一度だけ生成される

#### Scenario: 削除に含める
- **WHEN** 利用者が設定から地図データの削除を選ぶ
- **THEN** 抽出ファイルとともに派生データも削除される

#### Scenario: 生成の失敗
- **WHEN** 派生データの生成がエラーで終わる
- **THEN** その理由が短く示され、地図ページを除いた冊子の作成は続けられる

#### Scenario: 同じ通りの一本の線
- **WHEN** 同じ道路種別のwayが交差点ではなく途中で連続する
- **THEN** 派生データではそれらが1つの地物として統合され、印刷地図では分断されない同じ線として描かれる

#### Scenario: 印刷で見えない点
- **WHEN** 道路や面の幾何に、印刷の縮尺で判別できない間隔の点が含まれる
- **THEN** その点は派生データには格納されず、紙面上の形状は保たれる
