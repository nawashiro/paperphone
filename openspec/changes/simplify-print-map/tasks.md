## 1. 道路の統合と幾何の簡素化（構築側）

- [ ] 1.1 `_scan_places_and_features` 内で、同じ`road_class`のwayを端点一致の連鎖で統合する（分岐・交差点では分かれ、閉じた連鎖は1レコード）。テスト: 合成PBFで連鎖の統合・非統合・閉じた連鎖を確認する。
- [ ] 1.2 投影座標の道路折れ線と面のリングにDouglas–Peucker（許容値は1メートルの定数）を適用する。簡素化で幾何が無効になった対象は元の幾何を格納する。テスト: 結果の幾何が有効で、元の幾何とのずれが許容値を超えないこと。
- [ ] 1.3 統合と簡素化を同じ走査パス内で行い、PBFの走査回数が増えないことをテストで確認する。
