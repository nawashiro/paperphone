# Spec Delta

## ADDED Requirements

### Requirement: 単一実行ファイルでの配布
アプリはインストール作業なしで起動できる単一実行ファイル（AppImage）として配布されなければならない（SHALL）。GTK 4、libadwaita、PyGObject、PDF描画・画像関連のGI、日本語用のフォールバックフォントを同梱し、基盤環境（glibc 2.35）で動作しなければならない（SHALL）。同梱内容の更新を利用者に自動で強制してはならず（MUST NOT）、配布ページからの入手方法をREADMEに示さなければならない（SHALL）。

#### Scenario: クリーン環境での起動
- **WHEN** EDS等のホスト連携が設定済みのクリーンなGNOME環境（glibc 2.35）で実行ファイルを起動する
- **THEN** インストール・依存環境の事前準備なしで主画面が表示される

#### Scenario: 年代の異なる環境での起動
- **WHEN** glibcが基盤環境より新しいLinux環境で実行ファイルを起動する
- **THEN** 同じ実行ファイルがそのまま動作する

#### Scenario: ホスト側依存が不足する場合
- **WHEN** ホストのシステムでEvolution Data ServerのD-Busサービスが利用できない
- **THEN** 連携先の案内を短く表示し、技術的な例外詳細を主画面に出さない

#### Scenario: ホストEDSの読取
- **WHEN** ホストに設定済みのEDSアカウントがある
- **THEN** 配布形式に依らず予定・TODO・連絡先を読取れる

## MODIFIED Requirements

### Requirement: 配布環境でのデスクトップ連携
配布されたGNOMEアプリはホストの予定・タスクリスト・アドレス帳、位置情報、ファイル保存と印刷に必要最小限の権限で接続し、未設定の場合は設定案内を提供しなければならない（SHALL）。接続は実行時にホストのシステム設定や他アプリのデータを書き換えてはならない（MUST NOT）、アプリの設定と利用者の指定した出力先だけが更新される。

#### Scenario: タスクリストが未登録
- **WHEN** デスクトップ側に利用可能なタスクリストが登録されていない
- **THEN** 「未完了タスクがない」状態と区別し、CalDAVタスクリストを登録するための案内を表示する

#### Scenario: 無修正の実行
- **WHEN** 配布されたアプリを起動から終了まで使う
- **THEN** ホストのシステム設定・他アプリのデータは変更されず、アプリの設定と出力先だけが更新される
